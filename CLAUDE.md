# Instruções do Projeto

## Fluxo de trabalho obrigatório para QUALQUER mudança

1. **Analisar primeiro** — ler o código relevante antes de propor qualquer alteração
2. **Criar tarefas** — usar TaskCreate para listar cada mudança necessária
3. **Aguardar aprovação** — apresentar a lista de tarefas ao usuário e esperar ele mandar executar
4. **Nunca implementar** sem que o usuário tenha visto as tarefas e dado o sinal verde
